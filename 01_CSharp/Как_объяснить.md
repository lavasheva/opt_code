# Как объяснить работу

Я выделила разбор CSV в отдельный CsvParser, а DataImporter оставила управлять импортом. Проверка processed теперь в одном методе. Вывод и сохранение можно подменять в тестах. Я не стала незаметно менять повторный импорт: исходник накапливал записи, и этот контракт сохранён.

Что открыть: Program.cs, затем Tests.cs.
Что показать: dotnet run -c Release -- --no-pause и dotnet run -c Release -- --test.
Вопрос про catch: причина сохраняется в LastError, а исключение по-прежнему не выходит наружу, как в исходнике.
