## Требования

- .NET SDK 8 для работ на C#.
- Python 3.10 или новее для Python-работ.
- Docker Desktop с Linux-контейнерами и Docker Compose для микросервисов и дашборда.
- Postman или Node.js для проверки API микросервисов.

## C#

Из каталога соответствующей работы:

```powershell
dotnet run -c Release
dotnet run -c Release -- --test
```

Для первого задания параметр `--no-pause` отключает ожидание нажатия клавиши.

## Python

Создание окружения из корня репозитория:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

Из каталога Python-работы:

```powershell
..\.venv\Scripts\python.exe -m pytest -q
..\.venv\Scripts\python.exe ..\benchmark_python.py time
```

Для измерений памяти вместо `time` указать `memory`. Наборы тестов запускаются из своих каталогов, так как содержат одноимённые модули `original` и `optimized`.

## Микросервисы

В каталоге `05_Микросервисы` выполнить `setup.ps1`. API Gateway доступен по адресу `http://localhost:8000`.

Проверка API: импортировать `Postman_collection.json` и запустить коллекцию либо выполнить `node smoke.mjs`. Сценарий `node test_reliability.mjs` проверяет отказ и восстановление Orders.

## Космический дашборд

В каталоге `06_Космический_дашборд` выполнить `setup.ps1`. Веб-приложение доступно по адресу `http://localhost:8080/dashboard`, Rust API — `http://localhost:8081`.

Сценарии приёмки и команды тестирования приведены в `ACCEPTANCE.md`. Для JWST и AstronomyAPI требуются собственные действующие ключи. Переменные окружения перечислены в `.env.example`. Рабочие `.env` не включены в репозиторий.
